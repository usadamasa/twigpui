この数字の出どころ

件数は usage.json (アプリ側の集計。X の同日 dedup を再現したもの)。 時刻は課金済み post id の snowflake から起こした作成時刻で、課金時刻そのものではない。 自動更新が数分おきに先頭ページを読むので、ずれは概ねポーリング 1 回ぶんに収まる。 購入より前に作られた post は購入時刻へ寄せてある。残高切れはログの最初の HTTP 402。 金額は X の公開単価を掛けた見積りで、請求額は Developer Console にしか無い。
